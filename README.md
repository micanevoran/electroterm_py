# ElectroTerm Paraguay — Sitio web

Sitio institucional de ElectroTerm para su desembarco en Paraguay: ingeniería
de climatización de alta complejidad para hospitales, data centers, edificios
corporativos e industria.

## Estructura
- `index.html` — Home
- `nosotros.html` — Nosotros
- `servicio.html` — Nuestro servicio
- `recursos.html` — Recursos técnicos
- `articulo-quirofano.html` — Artículo
- `css/styles.css` — sistema de marca base
- `css/paraguay.css` — componentes específicos del sitio PY
- `js/main.js`, `js/ficha.js` — interacciones (navbar, carrusel, modal de fichas)
- `img/` — imágenes

Sitio estático (HTML/CSS/JS). Abrir `index.html` en el navegador o servir con Live Server.
